# 本地 Web 邮件阅读

Web 正文读取本地数据库；已读／未读操作会连接邮箱服务器同步状态，不会发送邮件。

## 打开指定邮件

```sh
jianxin -a 862945626@163.com list
jianxin open <邮件ID>
```

`open` 会启动临时本地服务，并在默认浏览器打开指定邮件。完整邮件 ID 可跨账号查找；前缀不唯一时，用 `-a <邮箱>` 限定账号。

只获取阅读网址、不打开浏览器：

```sh
jianxin open <邮件ID> --no-open
```

每次 `open` 的临时服务使用随机端口，30 分钟没有请求后自动退出。首页直接使用 `http://127.0.0.1:<端口>/`，不附加随机路径。服务仅允许本机访问。

## 持续运行 Web 阅读端

```sh
jianxin web
jianxin web --port 8788
jianxin web --message <邮件ID> --open
```

命令输出完整网址。手动打开它即可进入基于 Timeless / jxui 的邮件工作区：
浅灰邮箱侧栏、对话列表和右侧阅读面板。侧栏常驻多个邮箱及各自的 Inbox 等文件夹，支持独立折叠。邮箱状态复用 TUI 的最后同步记录，每 5 秒读取一次；状态刷新不触发远端同步。可切换账号与文件夹，筛选未读，
按主题、发件人和摘要关键词搜索。列表每页 50 条对话，相同 thread id 聚合为一条，
徽章显示邮件数；打开对话后按时间正序展示首封邮件及后续回复，超过 50 封可继续加载。
窄屏使用单栏阅读，点击「返回列表」切回列表；浏览器前进和后退恢复所选对话及筛选。

左侧「全部邮件」「未读邮件」均显示所有已配置邮箱的本地邮件总数（含 0），
按 TUI 的规则去除同一邮箱不同文件夹中的邮件副本，排除已删除邮件。
总数不受当前搜索、文件夹或分页影响，每 5 秒随邮箱状态刷新，已读同步后也会刷新。

右上角通知中心记录邮箱状态更新、邮件加载和已读同步错误，显示未读数量。
可将单条通知标为已读或未读，也可全部已读；打开面板不会自动标为已读。
重复错误合并计数，最多保留 100 条。记录保存在当前浏览器来源的本地存储；
服务换用其他端口后，浏览器来源不同，历史不共享。

在地址后追加 `/components` 可查看 design + jxui 组件示例。
前端源码、视觉契约和构建方法见 [frontend/README.md](../frontend/README.md)。
刷新按钮读取本地数据，不会强制进行远端同步。

外部本机程序可调用 `POST http://127.0.0.1:<端口>/api/notifications` 发送系统通知，
`Authorization: Bearer` 请求头必须携带 `general.api.token` 中的 token。参数和认证方式见 [HTTP notification hook](desktop-notifications.md#http-notification-hook)。
持续接收推送时使用 `--idle-seconds 0` 保持 Web 服务运行。

终端按 `Ctrl-C` 停止服务。后台同步产生新邮件后，刷新列表页即可看到。

服务只监听 `127.0.0.1`，不开放局域网访问。端口被占用时可更换端口或用 `--port 0` 自动分配。`--idle-seconds N` 可以指定空闲退出时间，默认 `0` 持续运行。

## TUI

展开对话并选中一封邮件后，按 `b` 在浏览器阅读。保持 TUI 可继续操作；HTML 页与 TUI 使用相同配置和本地邮件数据库。

## 已读／未读

- 单封邮件在可见页面加载正文后自动标为已读；GET 页面请求本身不会修改状态。
- 对话页默认只展开首封邮件。后续回复展开并加载正文后才上报已读，未展开的邮件保持原状态。
- 每封邮件旁有「标为已读／标为未读」按钮，显示同步中的提示以及同步结果。
- 先同步邮箱服务器，成功后更新本地标记、文件夹和对话未读数量，TUI 会读取数据库变化自动刷新。
- 网络或授权失败时原状态不变，页面提示重试；不会把失败操作显示为已成功。
- 手动标为未读后，该页面不会立即自动改回已读；重新打开阅读页会重新触发自动已读。

## 正文安全与限制

- 默认使用 HTML 正文，无 HTML 时显示纯文本；可以切换视图。
- 邮件正文自动随内容和图片加载调整高度，使用整页滚动，不提供正文内滚动条。
- 邮件经过 HTML 安全清理，在无脚本权限的 sandbox iframe 中渲染，脚本、表单、嵌入网页和自动跳转被禁用。
- 默认加载 HTTPS 远程图片；发件人可能通过图片获知阅读行为。点击「屏蔽远程图片」可关闭加载，此选择保留在当前服务网址的查询参数中，并在页面内切换对话时沿用。
- 正文链接在新标签页打开，不发送本地页面的 Referer。
- 当前不提供附件下载或 `cid:` 内嵌附件图片；某些特殊样式会因安全限制无法完全还原。
- 邮件中的链接仍可能是钓鱼链接，打开前检查目标地址。

## 邮件 Agent

右上角「邮件助手」打开右侧 Agent / MCP 面板。参考 Agentic Inbox 的交互，
Agent 可以搜索本地邮件、读取完整对话、总结未读、拟定回复以及提议修改已读状态。
切换邮箱会切换独立会话；全局导航使用所有已配置邮箱。选中的对话作为引用交给 Agent，
Agent 再按需读取内容。打开面板本身不会调用模型。

在现有配置文件的 `general` 中合并以下配置，保留已有邮箱、API token 等配置：

```json
{
  "agent": {
    "base_url": "https://你的模型服务地址/v1",
    "model": "支持工具调用的模型名称",
    "api_key": { "file": "/绝对路径/模型密钥文件" },
    "timeout_secs": 60
  }
}
```

配置支持 OpenAI 兼容的 `/chat/completions`、流式响应和 function tools。
`api_key` 也支持已有的 `env` / `keychain` / `command` 引用；macOS 应用不保证继承终端环境变量，
使用密钥文件或钥匙串更适合应用启动。密钥文件只放密钥文本，并限制文件权限。
本机模型允许使用 `http://127.0.0.1:<端口>/v1` 且省略 `api_key`；远程接口要求 HTTPS 和密钥。
修改后重启 Web 服务，未配置时展示配置提示。

- 回复流式显示，工具执行记录同步显示；每次最多 5 轮模型请求、每轮最多 4 次工具调用。
- 邮件内容会发送给配置的模型服务。邮件和模型输出按不可信数据处理，Web Agent 只暴露读取和提议工具。
- 回复草稿可修改主题、正文，确认后保存到草稿箱；不提供发送工具。收件人由原邮件的 Reply-To / From 确定。
- 已读状态变更同样需要点击确认，成功后刷新邮件列表及数量。确认卡片 10 分钟后过期，可取消。
- 停止操作阻止后续工具执行与结果发布；正在等待网络数据的请求在返回数据或超时后结束，每次请求超时限制 10–120 秒。
- 聊天按邮箱保存在数据目录 `agent-chats/`，目录权限 0700、文件权限 0600，不存模型密钥。清空会话也清除该邮箱的待确认操作。
- 会话长度和邮件工具结果有上限，长内容可能被截断。错误也记录到通知中心。
- MCP 标签提供现有 `jianxin agent` stdio 接口配置，供外部 Agent 客户端使用。

Web conversations expand all loaded messages by default. Once their bodies load in a visible reader, read flags are written back to the mailbox and local database. Read/unread updates and the following list refresh run silently; failed writes remain visible and retryable. Writes are queued so opening multiple messages does not exceed the server write limit.
