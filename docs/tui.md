# TUI 终端界面

`eeeemail tui` 打开交互式终端 UI；不带子命令直接运行 `eeeemail` 也是同一个入口。

```sh
eeeemail tui        # 等价于 eeeemail
eeeemail -a gmail   # -a 对 TUI 无效：文件夹面板会列出全部配置账号
```

TUI 不支持 `--json`。

## 界面布局

```text
┌──────────────┬───────────────────────────────┐
│ Folders      │ All Email                     │
│ ✉ All Email 8│ ●  09-15 10:0 gmail alice  …  │
│ gmail        │    09-14 18:3 gmail bob    …  │
│   INBOX    12│    09-14 09:0 work  carol  …  │
│   Sent       ├───────────────────────────────┤
│ work         │ Message                       │
│   INBOX      │ From    alice@example.com     │
│              │ Subject …                     │
│              │ （正文预览，可滚动）           │
├──────────────┴───────────────────────────────┤
│ [list] q quit · f fetch · t threads · …      │
└──────────────────────────────────────────────┘
```

- 左侧是多账号文件夹面板（未读数以黄色显示）：顶部一行 `✉ All Email` 汇总所有账号，下面按账号分组列出各自的文件夹（组头是账号别名，不可选中）。右上是邮件列表，右下是选中邮件的预览，最底一行是状态栏。
- 选中 `All Email` 时，列表合并展示所有账号的所有邮件（同一封邮件在多个文件夹只显示一次，优先显示收件箱副本），并多出一列 `ACCOUNT` 标明归属；搜索结果同样跨账号并带此列。
- 状态栏显示当前焦点面板（`[folders]` / `[list]` / `[message]`）、当前账号 `n/m`、后台任务的旋转指示器和最近一次操作的结果；空闲时显示按键提示。
- 界面是离线优先的：所有面板都从本地 SQLite 渲染，同步和发信在后台线程进行，慢服务器只会看到转圈，不会卡住界面。
- 本地数据库为空时（首次使用）会自动开始一次同步；之后按 `f` 手动同步全部账号。

## 快捷键

### 导航

| 按键 | 说明 |
|------|------|
| `Tab` / `Shift+Tab` | 在文件夹 → 列表 → 正文三个面板间循环切换焦点 |
| `j` / `k`、`↑` / `↓` | 移动光标；焦点在正文面板时滚动正文 |
| `g` / `G` | 跳到第一 / 最后一条 |
| `PageUp` / `PageDown` | 正文滚动 10 行 |
| `Enter` | 文件夹面板：重新加载邮件并聚焦列表；列表：打开（会话模式下先钻入会话）；打开邮件会标为已读并把焦点移到正文 |
| `Esc` | 会话内返回会话列表；否则清除搜索词和状态消息 |
| `?` | 帮助浮层，按任意键关闭 |

### 邮件操作

| 按键 | 说明 |
|------|------|
| `f` / `F5` | 从服务器同步**所有**配置账号（增量，逐账号汇总结果） |
| `t` | 在平铺列表和会话视图之间切换 |
| `c` / `m` | 写新邮件 |
| `r` | 回复高亮的邮件 |
| `u` | 切换已读 / 未读 |
| `*` / `s` | 切换星标 |
| `d` | 删除高亮的邮件 |
| `/` | 搜索本地数据库 |

所有写操作都是乐观更新的：按键后界面立即生效（`u`/`*` 翻转标记，`d` 从列表移除邮件，并同步会话和文件夹的未读/总数计数），写入服务器在后台线程进行，期间可以继续浏览、翻面板、做别的操作；写入失败时自动回滚并在状态栏显示错误。`Enter` 打开邮件时的自动标已读也是如此。界面本身只从本地数据库渲染，因此任何网络慢都不会卡住操作。

### 账号与退出

| 按键 | 说明 |
|------|------|
| `a` / `A` | 跳到上一个 / 下一个账号的第一个文件夹（配置了多个账号时可用，状态栏会显示 `n/m`） |
| `q` | 退出 |
| `Ctrl+C` | 退出，在任何浮层（撰写、搜索、帮助）里也有效 |

### 多账号与 All Email

- 文件夹面板同时列出**所有**配置账号：`✉ All Email` 汇总行 + 每个账号一组文件夹。
- 光标落在某个文件夹上时，该账号成为"当前账号"（`c` 写信的发件账号，状态栏 `n/m`）；停在 `All Email` 上时保持上一个当前账号。
- 标记已读、星标、删除、回复等操作始终作用于**邮件所属的账号**，与当前光标在哪个账号分组无关。
- 会话视图（`t`）在 `All Email` 下合并展示所有账号的会话，选中文件夹时只显示该账号的会话。

## 会话视图

按 `t` 切换到会话视图：列表每行是一个会话，列为最后活动时间、主题、邮件数；有未读时显示 `总数 (未读数)`。`●` 表示会话内有未读。

- 会话上按 `Enter` 钻入：邮件按时间正序排列（`#1` 最旧），光标停在最新一封；再按 `Enter` 打开某封邮件，`Esc` 逐级返回。
- 会话内 `u` 切换已读、`d` 删除后，会话列表会立即刷新。
- 会话归组规则与 CLI 的 `eeeemail threads` 一致：优先 `In-Reply-To`/`References` 祖先链，其次服务端线程 key（Gmail `X-GM-THRID`、IMAP `THREAD=REFERENCES`）、Outlook `Thread-Index` 根，最后是归一化主题。
- 切回平铺列表（再按 `t`）会清空搜索词。

## 搜索

按 `/` 弹出输入框：`Enter` 执行，`Esc` 取消，`Backspace` 删字符。搜索是本地的（对主题、摘要、正文、发件人的子串匹配）且**跨所有账号**，结果直接替换邮件列表，标题显示 `Search: 关键词`，每行带 `ACCOUNT` 列。

搜索结果始终是平铺的邮件列表（会话模式下会自动切回平铺）；按 `Esc` 清除搜索，恢复当前文件夹。

## 撰写与回复

按 `c`（或 `m`）打开撰写浮层，字段依次是 To、Subject、Body，底部是 `[ Send ]` 和 `[ Cancel ]` 按钮：

| 按键 | 说明 |
|------|------|
| `Tab` / `Shift+Tab` | 在字段和按钮间移动 |
| `Enter` | 在 To / Subject 上跳到下一字段；在 Body 上换行；在 `[ Send ]` 上发送 |
| `Esc` | 取消并关闭 |

- To 支持逗号分隔的多个地址。
- 没有收件人时不会发送，底部提示 `no recipients — fill in To`。
- 发送在后台进行，浮层标题显示 `sending…`，期间忽略输入；失败时浮层保留，错误显示在底部。
- 发送成功后浮层关闭，状态栏显示结果，列表自动刷新。
- 配置了 `general.compose.signature` 时，签名会自动以 `-- ` 分隔块附加在正文末尾。

按 `r` 回复高亮的邮件，表单自动预填：

- To 取 `Reply-To`（优先）或发件人，且不会回复给自己；
- 主题自动加 `Re:` 前缀（已有则保留）；
- 正文预填引用原文（`>` 引用 + `xxx wrote:` 署名行），光标直接落在正文上；
- 自动携带 `In-Reply-To`/`References` 线程头，回复在各家客户端都会归入同一会话。

## 相关配置

TUI 的行为受 `config.json` 中这些字段影响：

```json
{
  "general": {
    "sync": {
      "page_size": 50
    },
    "compose": {
      "signature": "Zhang San\nzhangsan@example.com"
    }
  }
}
```

- `general.sync.page_size`：文件夹列表和会话列表加载的条数（TUI 中限制在 20–500，默认 50）。
- `general.compose.signature`：撰写和回复时自动附加的签名。

账号与端点配置见 [cli.md](cli.md#配置)。
